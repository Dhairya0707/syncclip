# Pricing — SyncClip

SyncClip is a 100% free, real-time online clipboard tool. There are no paid tiers, no subscriptions, no ads, and no login requirements.

## Free (Default & Only Tier)
- **Price:** $0 / forever
- **Billing:** None (No credit card or payment info required)
- **Login:** None (Zero signup, 100% anonymous sessions)
- **Session Limit:** Unlimited active sessions
- **Device Limit:** Unlimited connected devices per session (Android, iOS, Windows, Mac, Linux)
- **Sync Speed:** Sub-100ms real-time sync via WebSockets
- **Data Retention:** 24-hour automatic data purge
- **Privacy Features:** Burn After Reading (self-destructs after reading), SSL/TLS 1.3 encryption, zero log retention
- **Supported Content:** Plain text, URLs, JSON, Code snippets, OTPs, terminal commands

## Enterprise / Self-Hosted
- **Price:** $0 (Open architecture, browser-native)
- **Commercial Use:** Allowed without restrictions
