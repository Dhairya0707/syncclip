## 6. Design Rules (Quick Reference)

To keep all social assets on-brand:

| Token                 | Value                       |
| :-------------------- | :-------------------------- |
| **Headline Font**     | Newsreader (Serif)          |
| **UI / Body Font**    | Space Grotesk               |
| **Code / Label Font** | JetBrains Mono              |
| **Background**        | `#FFFFFF` — pure white only |
| **Primary Text**      | `#000000` — pure black      |
| **Accent**            | `#057DBC` — Action Blue     |
| **Border Radius**     | `0px` — no rounded corners  |
| **Borders**           | 1–2px solid black           |
